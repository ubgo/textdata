# Getting started

Three short guides that take you from `go get` to a first read, a first edit and the command line. Each one runs a program under [`examples/getting-started/`](../../../examples/getting-started/) and shows its real output.

| Guide | What you learn | Example |
|---|---|---|
| [install-and-first-read.md](install-and-first-read.md) | `go get`, `dotenv.Read` and `dotenv.Open`, `jsonc.Read` and `jsonc.Open`, reading by path, decoding into a struct | [`first-read`](../../../examples/getting-started/first-read/) |
| [edit-and-save.md](edit-and-save.md) | edit a `.env` and a JSONC file and save them with every other byte unchanged | [`edit-save`](../../../examples/getting-started/edit-save/) |
| [textdatactl.md](textdatactl.md) | install the binary, `version`, the dotenv and jsonc verbs, running `textdatactl` inside your own program | [`embed-cli`](../../../examples/getting-started/embed-cli/), [`verb-tour`](../../../examples/cli/verb-tour/) |

Next: the [learning path](../../README.md) continues with the [dotenv](../dotenv/README.md) and [jsonc](../jsonc/README.md) guides. Not sure which format or module you need? See [Which format and which modules](../../choosing/format-and-modules.md).
